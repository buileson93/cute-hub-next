## Problem

Many buttons in deep UI areas (tables, toolbars, side panels) use both icons and text, which consumes significant space and leads to a cluttered interface. The user wants to move to an icon-only approach for these buttons, using hover tooltips to provide the text description.

## Strategy: "Icon First, Text on Hover"

1. **Identify Targets**: Focus on buttons within `StandardTable` toolbars, `BulkActionButton`, and specialized panel toolbars.
2. **Tooling**: Utilize `AppTooltip` (which handles `aria-label` automatically) to wrap icon-only buttons.
3. **Consistency**: Ensure all buttons in a specific toolbar follow the same pattern (either all icon-only or consistent styling).

## Detailed Changes

### 1. `BulkActionButton.tsx`

- **Current**: Renders `[Icon] [Label]`.
- **Change**: Render `[Icon]` only. Wrap the button in `AppTooltip` using the `label` prop as the tooltip content.
- **Exceptions**: Maintain full label for mobile view or when `size` is not `sm`.

### 2. `ThanhPhanTable.tsx` & `StandardTable.tsx` Toolbars

- **Edit Mode Button**: Refactor "Chỉnh sửa" / "Xong" to use `Pencil` / `Check` icons only.
- **View Mode Toggle**: The "Theo thành phần" and "Theo tài sản" buttons are quite large. Refactor to icon-only with tooltips.
- **Export/Action Buttons**: "Xuất CSV", "Bỏ chọn", "Sao chép mã" in `StandardTable` and `ThanhPhanTable` will be converted to icon-only.

### 3. `KhaiThemCumButtons.tsx`

- Refactor "Khai thêm hệ thống" and "Khai thêm thành phần" to use their respective icons (`Network`, `ComponentIcon`) + `Plus` as icon-only buttons with tooltips.

### 4. Global Sweep (Audit)

- Scan for `Button` usage in `src/components/mirats/` that uses `gap-1.5` or similar with both icon and text, and apply the "icon-only" rule where appropriate (compact areas).

## Technical Implementation

- Use `size="icon"` or a custom small size for buttons to keep them square and compact.
- Ensure `AppTooltip` is used for accessibility (aria-labels).
- Standardize on `h-7` or `h-8` height for toolbar items as per `ui-density.ts`.

## Verification

- Check all table toolbars (Asset/Component, Catalog, System).
- Verify tooltips appear correctly on hover.
- Ensure mobile responsiveness (may need to keep text labels on very small screens or use dropdowns).
