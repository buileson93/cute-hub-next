# MIRATS Astryx Safe Migration — P1: Install & Compile Probe

## Goal
Install the Astryx design system and StyleX dependencies, initialize the environment via CLI, and prove that the project can compile with these new libraries without affecting existing runtime functionality.

## 1. Validation & Setup
- Confirm `git status` is clean (Checked: Clean).
- Confirm `docs/astryx-migration-baseline.md` exists and reports success (Checked: Success).
- Verify React version is 19.2 (Checked: ^19.2.0).

## 2. Dependency Management
- Use `npm` to install dependencies with exact versions (no caret/tilde):
  - `@astryxdesign/core`
  - `@astryxdesign/theme-neutral`
  - `@stylexjs/stylex`
  - `@astryxdesign/cli` (as devDependency)
- Update `package.json` with an `astryx` script for easier CLI access.

## 3. Environment Initialization
- Run `astryx init` using the local CLI instance.
- Review any instructions or configuration files generated by the CLI.

## 4. Discovery & API Probing
- Execute and record output for the following commands:
  - `astryx component --list` (Identify available components)
  - `astryx component Button` (Verify Button API and import path)
  - `astryx component Badge` (Verify Badge API and import path)
  - `astryx docs migration --dense`
  - `astryx docs styling --dense`
  - `astryx docs theme --dense`

## 5. Isolated Compilation Probe
- Create `src/components/astryx-pilot/AstryxCompileProbe.tsx`.
- **Requirements for the Probe**:
  - Import `Theme` from `@astryxdesign/core/theme`.
  - Import `neutralTheme` from `@astryxdesign/theme-neutral/built`.
  - Import `Button` and `Badge` using paths discovered from the CLI.
  - Implement a valid React component that uses these primitives with verified props.
  - **Constraints**: This component must NOT be imported or used anywhere else in the application to prevent runtime regressions.

## 6. Verification & Build Integrity
- **Dependency Audit**: Ensure no duplicate React versions are introduced into the dependency tree (`npm ls react`).
- **Static Analysis**: Run `npm run typecheck` to verify TypeScript compatibility with StyleX and Astryx.
- **Testing**: Run `npm run test` to ensure existing tests still pass.
- **Production Build**: Run `npm run build:dev` to confirm Vite can successfully bundle the new libraries.

## 7. Results Documentation
- Document pinned versions and key CLI output.
- Record any findings regarding `moduleResolution` or peer dependency warnings.
- Prepare a checkpoint for Phase 2.

## Stopping Conditions
- Immediate stop and report if:
  - Peer dependency conflicts occur (especially React/React DOM 19.2).
  - Import subpaths do not resolve.
  - Duplicate React instances are detected.
  - Vite/TanStack configuration requires intrusive changes to support compilation.
