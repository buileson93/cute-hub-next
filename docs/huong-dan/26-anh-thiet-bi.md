# 26. Ảnh thiết bị (paste + crop)

## Cách upload nhanh
Ở mọi ô ảnh (Model, Thiết bị, Sự cố, Bàn giao):

### A. Paste từ clipboard
1. Chụp màn hình / copy ảnh vào clipboard.
2. Bấm chuột vào vùng ảnh trong form.
3. Nhấn `Ctrl+V` (Windows) / `⌘+V` (Mac).
4. Dialog **ImageCropDialog** mở ra.

### B. Chọn file
1. Bấm vùng ảnh → chọn file từ máy.
2. Dialog crop mở ra.

## Crop
1. Kéo khung vuông để chọn vùng.
2. Zoom bằng slider hoặc cuộn chuột.
3. Xoay bằng nút ⟳.
4. Bấm **Cắt & Lưu** — ảnh dạng avatar (vuông) được upload lên storage.

## Lưu ý
- Ảnh tự resize 512×512 cho avatar, 1600px cho ảnh chính.
- File > 10MB bị từ chối.
