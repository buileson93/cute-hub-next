# 07. Nhà sản xuất, Nhà cung cấp, Thương hiệu

Đường dẫn:
- `/danh-muc/nha-san-xuat`
- `/danh-muc/nha-cung-cap`
- `/admin/thuong-hieu`

## Thao tác chuẩn
1. **Thêm** — bấm **+ Thêm** → điền Tên, Website, Địa chỉ, Ghi chú → **Lưu**.
2. **Sửa** — menu `⋯` → **Sửa**.
3. **Xóa** — chỉ khi không còn Model tham chiếu.
4. **Hợp nhất trùng lặp** — vào `/admin/review` (xem [33](./33-data-review.md)).

## Gắn với Model
- Trong danh mục Model, chọn NSX + Thương hiệu từ dropdown.
- Không thể tạo Model mà thiếu NSX.
