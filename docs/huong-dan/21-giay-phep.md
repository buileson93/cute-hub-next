# 21. Giấy phép khai thác

Đường dẫn: `/giay-phep`.

## Thêm giấy phép

1. Bấm **+ Thêm giấy phép**.
2. Điền:
   - **Số giấy phép**, **Loại**.
   - **Đơn vị được cấp**.
   - **Thiết bị / Hệ thống liên quan**.
   - **Ngày cấp**, **Ngày hết hạn**.
   - **File scan** (PDF).
3. **Lưu**.

## Nhập hàng loạt

- Dùng file **Mau_Nhap_GP_KhaiThac.xlsx** (tải từ nút **Tải mẫu**).
- Bấm **Nhập Excel** → preview → **Xác nhận**.

## Cảnh báo

- Chỉ cảnh báo giấy phép **sắp hết hạn** (30/60/90 ngày).
- Giấy phép **đã hết hạn** vẫn được lưu trữ nhưng **không tính vào KPI**.
- Cảnh báo gửi qua Telegram nếu đã cấu hình bot.
