# 14. Network Overview (Obsidian graph)

Đường dẫn: `/topology` hoặc từ Sidebar → **Network Overview**.

## Mục đích

Xem toàn cảnh liên kết giữa Hệ thống ↔ Vị trí ↔ Thiết bị bằng đồ thị lực (react-force-graph-2d).

## Thao tác

1. **Zoom**: cuộn chuột. **Pan**: kéo nền.
2. **Bấm node**: hover hiện link preview; bấm mở drawer chi tiết.
3. **Fullscreen**: bấm nút ⛶ trên toolbar.
4. **Presentation Mode**: nút 🎬 — ẩn UI thừa, phù hợp trình chiếu.
5. **Radial Family Clustering**: bật nút **Clustering** → node cùng hệ thống gom quanh tâm theo Vogel sunflower phyllotaxis, màu theo hue.
6. **Lưu viewport**: hệ thống nhớ vị trí zoom/pan giữa các phiên.
7. **Lọc**:
   - Theo Đơn vị.
   - Theo Chủng loại.
   - Theo Nhãn.

## Tương tác

- **@mention** trong ghi chú tạo cạnh backlink → thấy trên graph.
- Bấm node → mở `EntityHoverCard` chuẩn.
